# Suhwan Jeong — CV

`https://1nteger-c.github.io/`에 게시되는 정적 CV 사이트입니다. 빌드 도구가 필요하지 않습니다.

## 내용 수정

이름, 소속, 경력, 논문, 실적, 연락처는 `index.html`에서 수정합니다. 레이아웃과 색상은 `styles.css`에서 조정합니다. 연도 표시는 `script.js`에서 갱신합니다.

현재 경력 정보는 본인 확인 내용을 우선 사용했습니다. 나머지 이력은 공개 [Notion CV](https://1nteger.notion.site/1nteger_c-37dfaba3a7034371a86d08f42677bb70)에서 선별했습니다. 논문 링크는 저자·행사·학회에서 공개한 PDF를, 코드 링크는 공개 GitHub 저장소를 사용했습니다.

## GitHub Pages 배포

이 저장소는 이미 GitHub Pages에 연결되어 있습니다. `main` 브랜치에 변경 사항을 푸시하면 사이트가 갱신됩니다.

모든 파일 참조는 상대 경로를 사용합니다.
